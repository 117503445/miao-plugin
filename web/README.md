# 个人角色配装静态站

用户需求：fork喵喵插件，展示本人原神、星铁账号的所有角色、当前武器／光锥与圣遗物／遗器评分，发布到 https://mihoyo.cloud.117503445.top ，纯静态网页。

本目录运行`npm ci && npm run build`生成`dist`，无需机器人、数据库或账号登录。配装快照：原神184173680（2026-10-15，94角色），星铁104496474（2026-10-07，74角色）。原神排除一条无元素的重复旅行者记录。缺失装备明确说明，不补造数据。

## 数据更新

在`tools/generate`运行Go程序，指定`-root`喵喵仓库根、`-out`本目录public、`-gs`GOOD、`-sr`Reliquary Archiver、`-locale`Enka本地化JSON。仅提取角色与已装备物品，素材按摘要去重。日期与UID须随来源更新转换器。

新角色名称补充位于`data/name-overrides.json`，使用theBowja/genshin-db简体中文数据核对。公开目录不含登录凭据、未装备背包、材料或抽卡记录。

## 评分

直接调用上游`models/artis/ArtisMark.js`、`ArtisMarkCfg.js`、`ArtisAttr.js`，打包默认权重与角色`artis.js`。浏览器适配层仅提供原函数依赖的元数据和配装接口，不另写评分公式。权重判断使用命座、装备、基础突破属性及静态套装增益；不模拟队伍临时增益、战斗状态或完整伤害，少数依赖完整面板阈值的规则可能与机器人实时面板不同。70分边界补显示MAX。

总分为五／六件之和，评级按固定部位数平均；配装不完整显示待完善。不是百分制，也不等于角色或队伍强度。
